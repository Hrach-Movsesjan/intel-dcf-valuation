# Intel (INTC) – DCF Equity Valuation

## Project Overview

An independent equity valuation of Intel Corporation using a Discounted Cash Flow (DCF) model, historical financial statements, analyst consensus estimates, and independently developed forecasts through 2035.

The project evaluates Intel's intrinsic equity value under different operating scenarios and assesses the financial performance required to justify its market valuation.

## Key Valuation Results

| Scenario | Implied Share Price |
|---|---:|
| Conservative Case | $12.62 |
| My Base Case | $31.87 |
| My Optimistic Case | $53.98 |
| Reference Market Price | $92.03 |

*Market price reference: 19 October 2026.*

## Methodology

The Excel valuation model incorporates:

- Historical income statements, balance sheets and cash flow statements
- Revenue, EBIT, CapEx, depreciation and working capital forecasts
- FCFF-based discounted cash flow valuation
- WACC estimation using a bottom-up beta
- Conservative, Base, Optimistic and customized scenarios
- WACC and terminal-growth sensitivity analysis
- Reverse DCF and ROIC versus WACC analysis

## Key Findings

The analysis indicates that Intel's reference market valuation exceeds the intrinsic values supported by the selected operating assumptions.

The Reverse DCF suggests that justifying the reference market price would require substantial improvements in revenue growth and profitability, including an EBIT margin of approximately 38.25% by 2035.
